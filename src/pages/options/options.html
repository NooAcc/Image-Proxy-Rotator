请求统计

只统计命中了你的规则的请求；其余请求本就该直连，不计入。 成功的判定是 HTTP 状态码小于 400。

「命中但直连」不为零时先查这一项。HTTPS 请求交给分流脚本时， 浏览器只给出「协议 + 域名 + 端口」，路径与查询串会被剥掉。所以依赖扩展名或路径的 规则（例如 \.jpg$）对 HTTPS 图片永远命中不了 —— 不报错，只是安静地直连。 把这类规则改成「域名」类型即可。

节点使用分布

归因靠请求的对端 IP —— 走代理时对端就是代理本身。只有 IP，没有端口， 所以多个节点共用同一个地址（只有端口不同）时无法区分，这些请求计入「无法归因」， 不会硬塞给某个节点。节点写成域名时要先测速一次才认得出。

批量导入

仅支持 HTTP / HTTPS 代理。每行一个：http://主机:端口、 http://用户名:密码@主机:端口，或 主机:端口（按 HTTP 处理）。 也可直接粘贴 base64 订阅内容；行尾 #名称 用于命名，# 开头的行是注释。

SOCKS4 / SOCKS5 / VLESS / VMess / Hysteria2 / Trojan / Shadowsocks 不受支持，粘贴后会被逐条列出并忽略。
